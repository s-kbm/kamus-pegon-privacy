Kebijakan Privasi

Kamus Pegon (com.ahmadsadam.aksarapegon)

Terakhir diperbarui: Agustus 2026

Kebijakan ini menjelaskan secara transparan data apa saja yang diproses aplikasi Kamus Pegon, bagaimana data itu digunakan, dan bagaimana cara kerja fitur alih tulisnya — agar pengguna memahami sepenuhnya sebelum menggunakan aplikasi.

1. Cara Kerja Fitur Alih Tulis

Teks Latin yang Anda ketik dikirim melalui koneksi internet ke server kami (Cloudflare Workers) untuk diproses menjadi aksara Pegon, lalu hasilnya dikirim kembali dan ditampilkan di aplikasi. Ini dilakukan supaya kamus dan algoritma alih tulis tidak dapat disalin dari perangkat pengguna.

  • Teks yang Anda kirim tidak disimpan secara permanen di server kami. Teks hanya diproses sesaat untuk menghasilkan alih tulis, lalu dibuang.
  • Kami tidak membaca, meninjau, atau menganalisis isi teks yang Anda kirim untuk tujuan lain di luar proses alih tulis itu sendiri.
  • Server kami mencatat alamat IP secara sementara (maksimal 24 jam) semata-mata untuk mencegah penyalahgunaan/spam pada server (rate limiting), bukan untuk melacak identitas atau perilaku pengguna.
  • Riwayat dan favorit alih tulis Anda disimpan secara lokal di perangkat Anda saja (localStorage), tidak pernah dikirim atau disimpan di server kami.

2. Iklan (Google AdMob)

Aplikasi ini menampilkan iklan melalui Google AdMob untuk mendukung pengembangan aplikasi secara gratis. AdMob dan mitranya dapat mengumpulkan serta memproses data berikut sesuai kebijakan Google:

  • ID iklan perangkat (Advertising ID) untuk personalisasi iklan
  • Alamat IP dan data lokasi umum (perkiraan wilayah, bukan lokasi presisi)
  • Data teknis perangkat (jenis perangkat, versi OS, dll)
  • Data interaksi dengan iklan (tampilan, klik)

Kami sendiri tidak memiliki akses ke data mentah yang dikumpulkan AdMob. Pengguna dapat mengatur preferensi iklan personalisasi melalui pengaturan Google di perangkat masing-masing (Settings → Google → Ads). Selengkapnya: Kebijakan Privasi Google dan Kebijakan Data AdMob.

3. Izin Aplikasi

Aplikasi hanya meminta izin akses internet, yang digunakan untuk: (a) menghubungi server alih tulis, dan (b) menampilkan iklan AdMob. Tidak ada izin sensitif lain (kamera, lokasi presisi, kontak, mikrofon, dll) yang diminta atau digunakan.

4. Data yang TIDAK Kami Kumpulkan

Untuk kejelasan, aplikasi ini tidak mengumpulkan: nama, email, nomor telepon, kontak, lokasi presisi (GPS), foto/media, atau data biometrik apa pun dari pengguna.

5. Anak-anak

Aplikasi ini tidak ditujukan khusus untuk anak di bawah 13 tahun dan tidak dirancang untuk menarik anak-anak secara khusus. Kami tidak sengaja mengumpulkan data pribadi dari anak-anak.

6. Keamanan Data

Seluruh komunikasi antara aplikasi dan server menggunakan koneksi terenkripsi (HTTPS). Kami menerapkan pembatasan akses (rate limiting) untuk mencegah penyalahgunaan server.

7. Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Perubahan signifikan akan diumumkan melalui pembaruan aplikasi atau catatan rilis di Play Store.
